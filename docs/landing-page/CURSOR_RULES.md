# PART VII — Cursor Implementation Rules

Before implementing any feature:

1. Read this specification in full.

2. Follow the Design Philosophy before making implementation decisions.

3. Do not invent colors.

4. Do not invent spacing.

5. Do not invent typography.

6. Do not introduce additional UI libraries.

7. Reuse components whenever possible.

8. Prefer composition over duplication.

9. Prefer accessibility by default.

10. Respect prefers-reduced-motion.

11. Use Framer Motion for animations.

12. Keep animation timing consistent.

13. Optimize for performance.

14. Build mobile-first while ensuring a premium desktop experience.

15. Every component should answer:

- Why does it exist?
- What does it teach?
- What user action should it encourage?

Before considering a section complete, verify that it aligns with:

• Product Vision

• Brand Personality

• Visual Philosophy

• Motion Philosophy

• Interaction Philosophy

• Accessibility Guidelines

• Performance Guidelines

If a design decision is ambiguous, choose the option that best reinforces clarity, professionalism, and progressive learning.

Never sacrifice readability or usability for visual effects.
