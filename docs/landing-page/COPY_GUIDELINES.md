# PART VI — Copywriting Guidelines

Writing Style

Write like Stripe.

Not like a marketing agency.

Every sentence should be:

• Short

• Clear

• Confident

• Human

Avoid:

❌ Revolutionize

❌ Cutting-edge

❌ Next-generation

❌ Game-changing

❌ Unlock your potential

Prefer:

✓ Learn with real projects.

✓ Practice with authentic datasets.

✓ Build skills employers expect.

✓ Measure your progress.

✓ Grow through guided experience.

Tone

Professional.

Educational.

Calm.

Optimistic.

Never exaggerated.

Every section should teach before selling.

The landing page should earn trust rather than demand attention.
